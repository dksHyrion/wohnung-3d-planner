# Abgepauste Grundrisse

Hier liegt später der eigene Grundriss als JSON, ohne Bildpixel.

Die Datei entsteht über den JSON-Export im Simulator. Geladen wird sie über den JSON-Import. `standard-55` bleibt die Beispielwohnung und ist kein Ersatz für diese Datei.

Eine `wohnung.json` wird nicht angelegt, solange der echte Grundriss nicht abgepaust ist.

Die automatische Sicherung des offenen Plans liegt nicht hier, sondern in `.autosave/plan.json` neben dem Programm.
